# jalu-mebel-blitar
Jalu Mebel Blitar, ber alamat di kabupaten Blitar. Kami berdiri sejak tahun 1998 sudah melayani pemesanan seluruh Indonesia. Dengan kualitas dan bahan yang terbaik untuk menjamin keunggulan pesanan anda. Kami sediakan semua kebutuhan rumah kalian, bisa request sesuai ukuran,model,dan keinginan. Untuk pemesanan bisa langsung wa atau cek lokasi.
